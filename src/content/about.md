Modelizer is a lightweight database modeling tool developed and maintained by [Laurent Haan](https://www.haan.lu) for teaching the database modeling process.

It is a technological successor to [Java Modelizer](https://modelizer.fisch.lu/) by Bob Fisch and follows the [naming conventions for database modeling](https://www.edu.lu/xcgnr).

[Open Modelizer online](https://www.modelizer.lu/) · [Source code on GitHub](https://github.com/haan/modelizer)

## Run locally on Windows

1. Download the latest release from [GitHub Releases](https://github.com/haan/modelizer/releases).
2. Unzip it anywhere on your computer.
3. Double-click `modelizer.bat`.
4. Open [localhost:8080](http://localhost:8080) in your browser.

The release includes a tiny local webserver based on [miniserve](https://github.com/svenstaro/miniserve).
